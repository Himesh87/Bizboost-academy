# BizBoost Academy — Static Edition

A self-contained, browser-only version of BizBoost Academy. It uses plain HTML, CSS and vanilla JavaScript. No Node.js, Express, PostgreSQL or backend server is required.

## Included
- Home, login, registration, dashboard, courses, simulator and contact pages
- Local profile/demo login
- Course progress stored in browser localStorage
- Marketing simulator and saved plan
- Caption, hashtag and content-idea mini tools
- Privacy and Terms pages
- Responsive mobile layout

## Important limitation
This is a static academic/demo website. It does not provide real server-side authentication or cloud accounts. Do not enter sensitive information. Contact submissions are not emailed.

## Run locally
Open `index.html` in a browser. For best results, you can also use VS Code with the Live Server extension, but no Node.js is required.

## GitHub Pages
Upload all files in this folder to a GitHub repository, enable GitHub Pages from the repository's Pages settings, and select the main branch/root folder.
